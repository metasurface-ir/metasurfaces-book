# مشارکت دانشجویان و ترجمهٔ کتاب

می‌توانید توضیح را بهتر کنید، خطا را اصلاح کنید، دفترچه یا شکل اضافه کنید یا صفحه‌ای را ترجمه کنید. سایت از Markdown و دفترچهٔ ژوپیتر، ناوبری، فرمول و شکل می‌سازد. [وضعیت ترجمه‌ها](translations.md) از کار تکراری جلوگیری می‌کند. مدرس مسئول بازبینی علمی و پذیرش درخواست ادغام است.

## مسیر مناسب خود را انتخاب کنید

| مسیر | مناسب برای | روش تحویل |
| --- | --- | --- |
| مرورگر GitHub | اصلاح کوتاه و متن | ویرایش فایل و درخواست ادغام |
| فورک و ویرایشگر محلی | فصل، دفترچه، شکل و ترجمه | شاخه در فورک و درخواست ادغام |
| تحویل به مدرس | مشارکت‌کنندهٔ تازه‌کار Git | فایل ویرایش‌پذیر، شکل، منبع و شرح تغییر |

پیش از کار بزرگ، یک Issue برای هماهنگی محدوده باز کنید. پس از پذیرش و ادغام، ساخت و انتشار موفق سایت را به‌روز می‌کند. صرف ارسال تغییر، به معنی انتشار نیست.

## ویرایش در مرورگر

1. [مخزن کتاب](https://github.com/metasurface-ir/metasurfaces-book) را باز کنید.
2. فایل داخل `translations/fa/` را انتخاب و روی ویرایش کلیک کنید. GitHub ممکن است ابتدا فورک بخواهد.
3. تغییر کوچک و مشخص بدهید و علت علمی یا زبانی آن را توضیح دهید.
4. Pull Request باز کنید، نتیجهٔ کنترل ساخت را ببینید و به بازبینی پاسخ دهید.

## ترجمه با فورک و شاخه

نام کاربری خود را جایگزین کنید:

```sh
git clone https://github.com/YOUR-USERNAME/metasurfaces-book.git
cd metasurfaces-book
git switch -c translate-chapter-03-fa
```

ساختار فارسی، مسیر انگلیسی را حفظ می‌کند؛ برای نمونه:

```text
chapters/02-waves-and-interfaces.md
translations/fa/chapters/02-waves-and-interfaces.md
```

صفحهٔ جدید را در `translations/fa/myst.yml` و نگاشت `translations/languages.json` اضافه کنید. نگاشت باید مسیر دقیق URL انگلیسی را ثبت کند. متن فارسی را با صفحهٔ اصلی تطبیق دهید و SHA-256 منبع بررسی‌شده را در `translations/source-lock.json` ثبت کنید. تغییر منبع انگلیسی، ساخت را تا بازبینی ترجمه متوقف می‌کند؛ هش را بدون مقایسهٔ محتوا عوض نکنید. مرجع اصلی فرمول‌ها و محاسبات همچنان مشترک است.

## چه چیزهایی را ترجمه کنیم؟

عنوان، توضیح، پرسش، دستور آزمایش، زیرنویس و متن جایگزین شکل، پاسخ خودآزمایی و محدودیت مدل را ترجمه کنید. اصطلاح فارسی را در نخستین کاربرد کنار English بیاورید و انتخاب واژه را به [واژه‌نامه](glossary.md) اضافه کنید. نماد، نام تابع، واحد، علامت، قرارداد زمانی، صفحهٔ مرجع و مرجع علمی را حفظ کنید. برای نمونهٔ کد، از بلوک کد و برای ریاضی از نشانه‌گذاری MyST استفاده کنید؛ جهت آن‌ها را دستی برعکس نکنید.

کد شبیه‌سازی و داده را به شاخهٔ مستقل فارسی تبدیل نکنید. خطای عددی را در منبع مشترک اصلاح کنید و هر دو زبان را بازبینی کنید. دفترچهٔ ترجمه‌شده، سلول‌های توضیحی فارسی و همان کدهای منبع را بدون نسخهٔ تکراری خروجی ذخیره‌شده نگه می‌دارد. هنگام ساخت، خروجی‌های مرجع از دفترچهٔ اصلی اضافه می‌شوند؛ دفترچهٔ منتشرشده و داخل ZIP قابل اجراست. هر تغییر کد باید در مرجع انگلیسی نیز اعمال و مستقل بررسی شود.

دو شماتیک فارسی در `translations/fa/assets/chapter-02/` و واژه‌های رابط آزمایشگاه در `translations/fa/explorer-strings.json` قرار دارند. فرمول‌های JavaScript از همان قالب انگلیسی گرفته می‌شوند. پس از تغییر قالب، کامل بودن واژه‌ها، رفتار کنترل‌ها و برابری عددی را بررسی کنید. نام کلیدهای JSON دانلودشده برای سازگاری ماشینی انگلیسی می‌ماند.

## کنترل و ارسال

[محیط ساخت](getting-started.md) را آماده و اجرا کنید:

```sh
python scripts/validate_translations.py
python scripts/build_bilingual.py
```

دو زبان، سوییچ همان صفحه، صفحات بدون ترجمه، معادله و کد، فونت فارسی، شکل، جست‌وجو و صفحهٔ کوچک را بررسی کنید. در دفترچهٔ محاسباتی جدید، هسته را از نو آغاز و همهٔ سلول‌ها را اجرا کنید. یک کنترل تحلیلی یا مستقل متناسب با مدل بیاورید؛ عنوان «اجراشده» را فقط برای کار واقعاً اجراشده به کار ببرید.

```sh
git add translations/
git commit -m "Translate Chapter 3 into Persian"
git push -u origin translate-chapter-03-fa
```

از شاخهٔ خود به `metasurface-ir/metasurfaces-book:main` درخواست ادغام باز کنید. صفحهٔ اصلی، ترجمه، تصمیم اصطلاح‌شناسی، وضعیت بازبینی و کنترل‌های انجام‌شده را ذکر کنید. اطلاعات خصوصی، کلید دسترسی و پاسخ‌نامهٔ تأییدنشده را در مخزن عمومی نگذارید. نقش همکاران و کمک هوش مصنوعی را مطابق قواعد دوره بیان کنید.

## فصل ۶ و منشأ شکل‌ها

برای فصل ۴، دفترچهٔ `notebooks/04-floquet-orders.ipynb` را از هستهٔ تازه اجرا و ذخیره کنید، سپس `python scripts/export_chapter04_figures.py` را اجرا کنید. پنج شکل اصیل و آزمون‌های قاعدهٔ انتخاب، صورت بستهٔ ضریب آرایه، افت میدان خروجی و ضرایب فوریهٔ فاز پله‌ای در همین دفترچه هستند. متن دفترچهٔ فارسی را هماهنگ و خروجی‌های عددی نسخهٔ ترجمه را خالی نگه دارید. مرورگر `interactives/floquet-explorer.html` زبان را از سند می‌گیرد؛ هر دو زبان، کنترل هندسه و فاز، انتخاب هارمونیک و صفحهٔ کوچک را بیازمایید. نقش نمادین، میدان اسکالر تجویزی و دستگاه حل‌شده را از هم جدا کنید. پیوند مرورگر باید زبانهٔ تازه باز کند و گزینهٔ دانلود آزمایشگاه مرورگری نداشته باشد.

دفترچهٔ روش‌های عددی را کنار `simulations/numerical_methods.py` و وابستگی لایهٔ دقیق حفظ کنید. از هستهٔ تازه اجرا، معتبرسازی و با اسکریپت‌های فصل ۶ صادر کنید. پس از صدور همهٔ تصاویر `python scripts/export_figure_provenance.py` را اجرا کنید؛ گزینهٔ `--check` فهرست را هنگام انتشار می‌سنجد. [راهنمای منبع و بازاستفاده](attribution.md) را رعایت کنید: مولد اصیل را ارائه و مجوز واقعی مادهٔ اقتباسی را بررسی کنید. سابقهٔ منشأ مسیر تولید را مستند می‌کند و تأیید کلی حقوقی نیست.

## شواهد و خروجی‌های فصل ۷

مدل مشترک `simulations/tunable_surface.py` و دفترچهٔ انگلیسی را ویرایش کنید؛ سپس همهٔ سلول‌ها و `python scripts/validate_chapter07.py` را اجرا کنید. کد دفترچهٔ فارسی را یکسان نگه دارید و سلول‌های متنی را ترجمه کنید. شماتیک‌ها را با `python scripts/export_tunable_geometry.py` و شکل‌های ذخیره‌شده، دادهٔ مرورگر و بستهٔ منبع را با `python scripts/export_chapter07.py` صادر کنید. مولد مرورگر، هش مدل و پارامترهای مرجع را با ارزیابی تطبیق می‌دهد. منشأ شکل‌ها را بازتولید، متن فارسی و قفل منبع را بازبینی و ساخت سخت‌گیرانهٔ دو‌زبانه را اجرا کنید. آزمایشگاه مرورگر در زبانهٔ جدید باز می‌شود؛ بستهٔ منبع شامل پایتون، دفترچه و داده است و فایل HTML آزمایشگاه برای دانلود ندارد.

## شواهد و خروجی‌های فصل ۸

مدل simulations/communication_link.py و دفترچهٔ انگلیسی را ویرایش و اجرا کنید؛ سپس python scripts/validate_chapter08.py را اجرا کنید. کد سلول‌های فارسی را یکسان و متن را ترجمه کنید. scripts/export_communications_geometry.py و scripts/export_chapter08.py را اجرا و منشأ شکل‌ها را بازتولید کنید. متن دو زبان و قفل منبع را بازبینی و ساخت سخت‌گیرانهٔ دو‌زبانه را اجرا کنید. مولد مرورگر هش مدل و پارامترهای سازگار با ارزیابی می‌خواهد. بستهٔ منبع شامل پایتون، دفترچه و داده است؛ آزمایشگاه مرورگر بدون گزینهٔ دانلود در زبانهٔ جدید باز می‌شود.

# بررسی‌های محاسباتی مرتبط

با [ms-09: پهنای باند طیفی](../labs/09-dispersion-lab.md)، [ms-10: سلول مستقل و ابرسلول](../labs/10-coupling-lab.md) و [ms-11: بهینه‌سازی کران‌دار با کنترل مستقل](../labs/11-inverse-design-lab.md) ادامه دهید. این بررسی‌های اجراشده از همان هندسهٔ مشخص تیغه‌ای استفاده و پاسخ طیفی، تقریب مدل و اعتبارسنجی طرح را به هم وصل می‌کنند. طراحی معکوس، مرجع تمام‌موج مستقیم برای مقایسهٔ بعدی هوش مصنوعی است.

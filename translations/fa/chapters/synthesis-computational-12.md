# بررسی‌های محاسباتی مرتبط

برای ادامه، [ms-09: پهنای باند طیفی](../labs/09-dispersion-lab.md)، [ms-10: سلول مستقل و ابرسلول](../labs/10-coupling-lab.md) و [ms-11: بهینه‌سازی کران‌دار با بررسی مستقل](../labs/11-inverse-design-lab.md) رو ببینید. هر سه با همون هندسه تیغه‌ای مشخص اجرا شده‌اند و پاسخ طیفی، خطای تقریب و اعتبارسنجی طرح رو به هم وصل می‌کنن. طراحی معکوس هم یک خط مبنای تمام‌موج مستقیم می‌ده تا بعداً نتیجه هوش مصنوعی رو باهاش بسنجیم.

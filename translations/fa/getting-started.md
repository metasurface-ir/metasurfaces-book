# شروع محاسبات و اجرای دفترچه

برای مطالعه و مرورگرهای کتاب نصب لازم نیست. اجرای پایتون محیط محلی می‌خواهد. همین محیط مشترک، دفترچه‌های تحلیلی و حل‌گرهای CPU فصل‌های موجود را پشتیبانی می‌کند؛ دستورهای خاص و کنترل اختیاری هر فصل در [فهرست آزمایشگاه‌های فارسی](labs/index.md) آمده است. مدل‌های دارای چند فایل را از ZIP کامل بگیرید؛ دفترچه‌های فصل‌های ۴ و ۱۰ مولد و توابع داخلی دارند.

## بستهٔ آمادهٔ فصل ۲

بسته را از آزمایشگاه دریافت کنید، ZIP را کامل استخراج کنید و ساختار پوشه‌ها را نگه دارید. فایل HTML داخل `interactives/` مستقیماً در مرورگر و بدون اینترنت باز می‌شود. برای اجرای دفترچه، Python 3.12 و محیط مجازی بسازید:

```sh
python -m venv .venv
```

در PowerShell ویندوز:

```powershell
.\.venv\Scripts\Activate.ps1
```

در Linux یا macOS:

```sh
source .venv/bin/activate
```

از ریشهٔ پوشهٔ استخراج‌شده:

```sh
python -m pip install -r requirements-labs.txt
python -m pip install jupyterlab
python -m jupyterlab
```

فایل `notebooks/02-waves-and-interfaces.ipynb` را باز کنید؛ هسته را از نو آغاز و تمام سلول‌ها را به‌ترتیب اجرا کنید. متن توضیحی فارسی است؛ کد و خروجی‌های عددی مرجع با ویرایش انگلیسی مشترک‌اند. NumPy و Matplotlib این مدل‌ها را روی CPU اجرا می‌کنند. پس از نصب محیط، دادهٔ خارجی، GPU یا حل‌گر تجاری لازم نیست.

## کنترل نتیجه

از ریشهٔ بسته اجرا کنید:

```sh
python scripts/validate_chapter02.py
```

گزارش را همراه نسخهٔ منبع، پارامترها و محیط ذخیره کنید. کنترل‌ها، سازگاری مدل‌های تحلیلی محدود را می‌سنجند و جای اندازه‌گیری یا شبیه‌سازی هندسهٔ نقش‌دار را نمی‌گیرند. یک پیش‌بینی و تغییر یک پارامتر را پیش از نتیجه‌گیری ثبت کنید.

## ساخت خود کتاب برای مشارکت

در نسخهٔ کامل مخزن، محیط ساخت صفحات را جدا از محیط محاسبات نگه دارید. ساخت به Python و Node.js 24 نیاز دارد؛ محیط محاسبات کتابخانه‌های علمی بیشتری دارد.

```sh
python -m venv .book-env
```

محیط را مانند بالا فعال کنید و از ریشهٔ مخزن اجرا کنید:

```sh
python -m pip install -r requirements.txt
python scripts/validate_translations.py
python scripts/build_bilingual.py
python -m http.server 8000 --directory _build/html
```

اگر `BASE_URL` تنظیم نشده باشد، انگلیسی در `http://localhost:8000/` و فارسی در `http://localhost:8000/fa/` است. در GitHub Pages مسیر پایه خودکار تنظیم می‌شود. پیش‌نمایش معمول `jupyter-book start` برای متن انگلیسی مفید است؛ سوییچ زبان و خروجی فارسی در ساخت دو‌زبانه اضافه می‌شوند. روش ارائهٔ تغییر را در [مشارکت](contributing.md) ببینید.

## اجرای دفترچهٔ روش‌های عددی فصل ۶

بستهٔ کامل منبع را از [آزمایشگاه فصل ۶](labs/06-numerical-lab.md) استخراج کنید یا از مخزن کامل استفاده کنید. `requirements-labs.txt` مشترک را نصب و `notebooks/06-numerical-methods.ipynb` را از هستهٔ تازه اجرا کنید. NumPy/SciPy/Matplotlib روی CPU و ماژول‌های `simulations/` مشترک‌اند. محاسبات لایهٔ قابل ویرایش از دادهٔ مقایسهٔ ثابت RCWA جدا هستند. کاوشگر مرورگر دادهٔ ذخیره‌شده را انتخاب می‌کند و آفلاین کار می‌کند.

`python scripts/validate_chapter06.py` ممیزی مرجع اعلام‌شده را اجرا می‌کند؛ پس از ذخیرهٔ اجرا و ممیزی، در مخزن کامل `python scripts/export_chapter06.py` را اجرا کنید. حل‌گر اجراشده لایهٔ یک‌بعدی FDFD با ضریب حقیقی، محیط بیرونی برابر و مرز تابشی گسستهٔ تطبیق‌یافته است. FEM/FDTD، PML، مقایسهٔ بین‌روشی سلول نقش‌دار و قطعهٔ محدود همچنان طرح تمرین‌اند.

# Companion website typography

These unmodified font files and their complete notices are copied from the companion website's `public/fonts/` directory. English prose and navigation use Inter; English display headings use the website's local Iowan Old Style / Georgia serif stack. Persian prose and navigation use Vazirmatn; Persian display headings use Playpen Sans Arabic.

Inter, Vazirmatn and Playpen Sans Arabic are distributed under the included SIL Open Font License notices. The source website records the Persian font upstreams as the official Google Fonts `ofl/vazirmatn` and `ofl/playpensansarabic` packages. Math rendering retains the book theme's LaTeX fonts; these prose fonts do not replace KaTeX or MathJax fonts.

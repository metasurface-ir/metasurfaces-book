# Original Chapter 3 figures

`fields.png`, `library.png`, and `spectra.png` are copied byte-for-byte from the
executed notebook's tagged Matplotlib PNG outputs by `scripts/export_chapter03.py`.
The field plots are Fourier reconstructions for the restricted TE ridge model.
The library plots use saved full-wave results, not an assumed phase mask.
Regenerate from the notebook after changing the model or parameters.

## Original geometry schematic

The SVG model view is generated by `node scripts/export_model_geometry.cjs`
using `templates/model-geometry.js` and saved model parameters. The same
drawing code is embedded in the offline explorers. Persian labels are generated
into `translations/fa/assets/` from the same implementation. No external artwork
is used; cuts, invariance, boundaries and phase planes are labeled explicitly.

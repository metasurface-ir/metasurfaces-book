# Original Chapter 5 scientific figures

Six PNGs are exported byte-for-byte from tagged, executed Matplotlib notebook
outputs by `scripts/export_chapter05.py`. Coverage, order powers, and field
reconstruction come from 05-beam-steering.ipynb. Focus, axial response, and
polarization come from 05-wavefront-models.ipynb. Their captions distinguish
full-wave TE results, local-mask estimates, scalar propagation, and ideal
Jones-matrix predictions. Regenerate from those notebooks after edits.

## Original geometry schematic

The SVG model view is generated by `node scripts/export_model_geometry.cjs`
using `templates/model-geometry.js` and saved model parameters. The same
drawing code is embedded in the offline explorers. Persian labels are generated
into `translations/fa/assets/` from the same implementation. No external artwork
is used; cuts, invariance, boundaries and phase planes are labeled explicitly.

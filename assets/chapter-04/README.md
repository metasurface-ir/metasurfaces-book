# Chapter 4 figures

The figures are original outputs from tagged plotting cells in
`notebooks/04-floquet-orders.ipynb`. They show analytical channel geometry and
prescribed scalar array factors, not full-wave efficiency.

After changing parameters, restart the notebook kernel, run all cells, save, then
run `python scripts/export_chapter04_figures.py` from the repository root.
Review the chapter and worked-example numbers when changing the reference case.

The browser explorer in `interactives/floquet-explorer.html` independently
implements the same stated channel equations in JavaScript. It does not read the
notebook's saved outputs and requires separate browser checks after changes.

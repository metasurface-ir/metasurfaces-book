# Contributors and credit

This book is maintained by the [metasurface-ir organization](https://github.com/metasurface-ir).
The current repository maintainer is [farhadinia0](https://github.com/farhadinia0).
Individual authorship and changes are recorded in the Git history and pull requests.

Students should supply their preferred public name, the pages/notebooks/figures
contributed, and their role (writing, translation, code, data, scientific review,
or accessibility review) in each contribution. Add approved credits here without
inventing names, affiliations, ORCID identifiers, or reviews that did not occur.

The project has used AI assistance for drafting, translation, code and checks.
AI tools are not listed as human authors; contributors and the instructor remain
responsible for verifying claims and deciding whether to publish them. Report
the assistance and actual human/scientific checks in each pull request.

Cited researchers are credited for the specific scientific sources, not implied
to have authored, reviewed or endorsed this book. Dependencies and theme authors
retain their own notices. See LICENSE for content/code reuse scopes.

# Chapter 3 response library

Generated by executing `notebooks/03-unit-cell-library.ipynb`, using
`simulations/unit_cell_te.py`. The CSV contains 50 width samples; JSON adds
material/geometry/phase conventions, environment, thresholds, and source SHA-256.
The `width_um` field is the swept parameter; the metadata's `parameters.width_um`
is the illustrative central geometry, not a replacement for each row's width.

Every library row was calculated at half-order M=24 (49 harmonics) and compared
with M=32 (65 harmonics). `delta_t`, `delta_power`, and `delta_phase_deg` quantify
those changes. `balance_error` and `solve_residual` are separate numerical checks.
They do not establish discretization convergence by themselves. `accepted` means
the row passed these published thresholds within this model and domain.

`validation.json` is produced by:

    python scripts/validate_chapter03.py --grcwa

Install `requirements-labs.txt`; also install `requirements-validation.txt` for
the optional grcwa comparison. The saved audit includes 18 independent analytical
film cases, a flat-interface artificial supercell, multiorder mirror symmetry,
near-interface field continuity, input guards, six M=48 spot checks, and eight
grcwa comparisons with raster refinements from 256 to 2048 cells. The two RCWA
implementations are distinct but belong to the same numerical method family.

The reference geometry is a 1D dielectric ridge, invariant along y, TE Ey,
with real constant indices and no loss. At the library wavelength/incidence,
only m=0 is open on either side, so totals equal the zeroth-order powers.
This is not a dataset for arbitrary pillars, polarization, angles, wavelengths,
finite arrays, dispersive materials, or fabricated devices. It has incomplete
transmission-phase coverage. It is a starter dataset, not evidence of a trained
AI model's generalization.

After editing parameters, regenerate both library files and the audit. Preserve
each experiment in its own version rather than mixing incompatible rows. Run
`python scripts/export_chapter03.py` after saving the notebook and validation
to update the chapter figures, embedded-data explorer, and downloadable bundle.

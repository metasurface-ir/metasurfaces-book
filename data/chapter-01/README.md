# Chapter 1 analytical sheet evidence

Generated by `notebooks/01-first-metasurface-model.ipynb` with
`simulations/intro_sheet.py`. The model is a reciprocal, mirror-symmetric,
lossless two-port sheet at normal incidence, in equal-impedance exterior media,
with a single polarization and only specular reflection/transmission.
It has no assigned geometry, material data, diffraction, polarization conversion,
absorption, or fabricated-device validation. No full-wave solver runs here.

The two all-pass channel functions define the even/odd scattering eigenvalues
Ce and -Cm. The electric-like/magnetic-like labels describe effective channels;
they are not extracted dipole moments. Matched channels over an entire spectral
sweep are an imposed idealization, not a verified broadband physical design.

`sheet-response.json` contains parameters, conventions, preset spectra, complex
reference coefficients, source hash, environment, and numerical checks.
`sheet-response.csv` exports the frequency responses. Phase at vanishing
transmission is undefined: JSON stores null and CSV leaves it blank.
The browser explorer independently evaluates the same analytical equations.

Run `python scripts/validate_chapter01.py` for limiting cases, independent
electric-only shunt identities, one- and two-sided power checks, full unitarity,
group-delay derivative refinement, input guards, and source provenance.
The audit tests 36 parameter combinations with 521 frequencies each. These
are analytical consistency tests, not a geometry-convergence study.

After a fresh saved execution and audit, run `python scripts/export_chapter01.py`
to copy tagged PNGs, publish the editable explorer template, and regenerate
the complete source ZIP. Changing parameters defines a new teaching experiment;
preserve its assumptions, source version, and validation record.

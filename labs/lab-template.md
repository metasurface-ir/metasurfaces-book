# Computational lab template

This page defines the writing structure for future labs. It contains no executed simulation.

## Lab record

Record the topic ID, title, notebook path, environment version, source commit or release, validation status, and verified deployment URL. Keep the deployment URL unset until publication succeeds. Preserve the same topic ID in the companion website's link record.

## Question and prediction

State the physical question, observable, and expected limiting behavior. Ask the reader to predict the outcome before running code.

## Prerequisites and theory bridge

Summarize the minimum concepts and link to the verified public lesson URL when available. Define coordinate directions, phasor convention, units, materials, and boundary conditions.

## Model and editable parameters

Expose physical and numerical parameters. Explain the governing equations, approximation regime, and the computational functions that implement them.

## Notebook and results

Add the runnable notebook, versioned environment, parameter tables, plotted outputs, and output-data provenance. Explain how to reproduce each figure.

## Validation and limitations

Include analytic checks and independent comparisons where possible. For numerical solvers, vary the relevant discretization, domain, truncation, and sampling parameters. Distinguish amplitudes from power, allowed channels from excited channels, and analytical results from full-wave evidence.

## Exercises and research discussion

Ask students to vary parameters, test assumptions, and explain discrepancies. Add cited research questions and an optional extension.
